# 視覺導航系統 (Visual Navigation System)

繁體中文 | [English](README.md)

> **註記：** 此專案由 [AGILAB Software Template](https://github.com/AGILAB-NTNU/SoftwareTemplate) 基礎架構初始化而成。

## 專案簡介

視覺導航系統是以視覺表示學習與機器人導航為主題的研究專案，目前仍在開發中；模型、訓練流程與使用方式都可能調整。

目前專案統一採用 **512 維 Latent Vector（潛在向量）**。現行實作請參考原始碼與組態設定。

## 開發

Python 環境定義於 [`environment.yml`](environment.yml)。訓練及工具腳本位於 [`scripts/`](scripts/)，相關設定位於 [`configs/`](configs/)。

待專案流程穩定後，再補上完整的環境設定與使用說明。
