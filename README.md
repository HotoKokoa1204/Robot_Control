## Overview

Visual Navigation System is a research project for visual representation learning and robot navigation. The project is under active development; its models, training pipeline, and usage instructions may change.

The current project convention uses a **512-dimensional Latent Vector**. See the source code and configuration files for the current implementation.

## Development

The Python environment is defined in [`environment.yml`](environment.yml). Training and utility scripts are in [`scripts/`](scripts/), with their settings in [`configs/`](configs/).

Detailed setup and usage instructions will be added when the project workflows are stable.
